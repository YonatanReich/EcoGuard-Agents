# Fire collection

Four independent sources, because no one of them sees a fire on its own.

| Folder | What it provides |
|---|---|
| `firms/` | NASA satellite heat detections - where instruments saw something hot |
| `effis/` | The European daily fire-danger rating for the region |
| `gibs/` | Satellite vegetation imagery - how much fuel there is and how dry |
| `fwi/` | The daily fire-weather index, calculated from stored weather |

A satellite detection is a warm pixel, not a confirmed fire. Deciding what to
make of it is the detector's job.
