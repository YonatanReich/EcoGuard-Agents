# Dashboard source

The operator's screen: a map of what is happening, with a card for each event
and the detail behind it.

| Folder | What it holds |
|---|---|
| `pages/` | The screens themselves |
| `components/` | The map, the cards, the legends and the controls |
| `types/` | The shapes the backend sends |
| `utils/` | Small helpers |
| `dev/` | Sample data for working on a screen without a backend |
