# Fire evaluation cases

Hand-written situations used to check the fire planner: an apartment fire in a
town, a large wildfire, an extreme case at the edge of a forest, a fire in the
middle of nowhere, and several where the evidence is weak, stale or missing
entirely.

The last group is the important one. A planner that does well on clear cases
and invents an answer when the evidence is missing is worse than one that says
it cannot tell.
